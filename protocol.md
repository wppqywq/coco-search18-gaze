# Frozen scope: COCO shared responses and personalization

**24 September 2026 - exploratory follow-up, not a new preregistration.** Based on the supplied `refactoring-proposal.pdf`. Execution settings below were locked before this follow-up produced diagnostic outputs. They are project decisions, not literature-established thresholds; earlier analyses of these data remain known.

**Question and outcome.** Which shared gaze-selection regularities generalize across images, and are personal target/distance offsets still needed after a modest improvement to the shared response? Predict the next fixation among the existing 32 x 20 equal-area candidates, conditional on the image, category cue and observed history. Use the current target-present COCO subset only. Keep first-record conditioning, invalid-prefix truncation and first target-entry inclusion unchanged.

**Inputs and isolation.** Reuse frozen ResNet18 category-template resemblance, GBVS saliency, geometric movement distance and decaying visit history. These are proxies, not task value, energetic cost or memory capacity. Preserve fit-only templates, leave-own-image-out fitting maps, fit-only scaling, image/near-duplicate grouping and all existing controls. Existing distance already has D and D^2. Freeze both evaluated test sets; use only the existing fit/dev observations for this exploratory follow-up. Never redraw splits to claim independent confirmation.

**Input gate before new model fitting.** Compare correct-category resemblance with the other category templates using fit/dev only. Separate pre-target-entry choices from the final target-entry choice; report image/category variability and uncertainty. Check all candidate positions, not only fixated cells. A target-box AUC alone does not establish task-specific guidance during search. If specificity is absent, unstable, or confined to the final step, stop the planned interpretation of personal target weights; do not compensate with a larger model. **Locked contrast:** convert each of the 18 category maps into within-image candidate midranks `(rank-0.5)/640`; at each chosen cell subtract the mean rank under the other 17 cues from the correct-cue rank. Use the existing grid and mean contrasts over transitions within each trial separately for pre-entry and target-entry phases. Gate on dev only, with 2,000 crossed subject/image-group bootstrap replicates (seed 2030) over trial means. Continue only if the pre-entry 95% interval is entirely above zero, both fixed dev image blocks have positive means, and at least 12 of 18 category means are positive. Any unmet condition stops the four-model run; a wide interval is inconclusive, not proof of invalidity. Report all phase/category means and counts. Rebuild templates only from unique fitting image/category crops, excluding the current image in every category for fit diagnostics, and verify reconstructed matched dev maps against the frozen maps (absolute tolerance 1e-6). This cue substitution is an input diagnostic, not a human manipulation or a controlled causal effect.

**Bounded descriptive checks.** Study only saccade amplitude, center tendency and revisit rate. Inspect per-person distributions and stability across fit-image blocks, accounting for image, category and fixation-order composition. Examine T/S/D/H correlations within entire choice sets and summarize by image. Coefficient stability and raw-behavior stability are distinct. Neither correlation nor ablation gains establish identifiable causal contributions. Use image-width units for amplitude and center distance, and a 0.06-width revisit radius around earlier points excluding the current fixation. Summarize trial means/distributions; adjust for image x category x order-bin (first, transitions 2-4, later) by subtracting the within-stratum participant mean, retaining strata with at least two participants. Report person A/B means and their Pearson correlation; with ten people this is descriptive. Form A/B by sorting image groups within each split by SHA256(`20260924:<group>`) and alternating assignments. Average candidate-wise Pearson correlations within image/category, then equally across images; undefined constant-feature correlations are missing, not zero.

**One planned 2 x 2 comparison.** Every cell retains the same personal spatial controls and all other shared controls.

| Shared response | No personal T/D offsets | With personal T/D offsets |
| --- | --- | --- |
| Existing T, D and D^2 parameterization | Existing M1 structure | Existing M2 structure |
| Fixed low-dimensional T/D splines | Same controls, shared flexible response | Same shared response plus the same two personal linear offsets |

Splines replace the corresponding shared main-effect terms; they do not add a model family, hidden state, factors or searched interactions. Keep the current first-transition controls. **Locked later comparison:** use a natural cubic basis with nodes at fit-candidate 5/35/65/95 percentiles, three nonconstant columns per factor and explicit linear tails. Duplicate nodes stop fitting rather than trigger basis search. Use one basis/scale per fit set and keep it fixed across its comparison models. Tune the common personal shrinkage over {1, 10, 100}; use the existing shared coefficient penalty 0.01 after scaling. Define practical gain as 0.005 bits/choice (a project convention, approximately 0.35% geometric probability improvement), and use the same crossed-bootstrap rule. Fit the full fit set and independent A/B fit-image blocks; compare each paired model on dev and dev A/B blocks. Select the simpler model only when the gain interval upper bound is below the practical margin; retain extra personal offsets only when the full-fit interval lower bound exceeds the margin and gains are positive for both independently fitted blocks. Otherwise report inconclusive. Repeat the paired comparison with history removed as a bounded sensitivity, not an extra tuning search. Fit basis/scaling on fitting images only. Do not choose these settings after looking at new comparison results.

**Evaluation and decisions.** Use dev log probability in bits/choice, image/participant uncertainty and conditional predictive checks of distance, center tendency and revisit probability under the same true histories. Prefer simpler models when added complexity yields no practically meaningful, precisely estimated gain; imprecision is inconclusive, not evidence of equivalence. Retain personal offsets only if their gains recur across image blocks and survive the bounded proxy/history checks. Check whether deleting weak history changes T/D conclusions before removing that control. These checks do not validate freely generated scanpaths or measure all predictable information; that would require a matched stronger reference.

**Stop boundary.** Run the input gate and bounded descriptive checks first; implement the four-cell comparison only if the gate passes. No new dataset, SceneWalk, DeepGaze, MCMC, duration/stopping model, video, closed-loop policy, latent PCA, clustering or new-participant adaptation. Archive prior work; do not make it a completion requirement. No new model results are claimed by this refactor.
